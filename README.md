📊 Project Description

This project presents an interactive HR analytics dashboard built using Tableau and Python to analyze employee attrition, workforce demographics, and job satisfaction.
The dashboard provides a comprehensive overview of key HR metrics to support data-driven decision-making and help organizations understand workforce trends.

🛠 Tools Used

* Tableau
* Python (Pandas, Seaborn, Matplotlib)
* Microsoft Excel

📈 Key Features

* **KPI Overview:**
  * Employee Count
  * Attrition Count
  * Attrition Rate
  * Active Employees
  * Average Age
* **Attrition Analysis:**
  * By department
  * By gender
  * By education field
* **Workforce Insights:**
  * Employee distribution by age group
  * Attrition trends across age groups
* **Job Satisfaction:**
  * Analysis across different job roles
  * Comparison of satisfaction levels

📊 Key Insights

* Higher attrition observed in specific departments such as Sales
* Majority of employees fall within the 25–35 age group
* Job satisfaction varies significantly across job roles
* Male employees show slightly higher attrition compared to female employees

1. Download the `.twbx` file or clone this repository
